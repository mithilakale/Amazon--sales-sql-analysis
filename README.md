# Amazon Sales Analysis – SQL & Power BI

## Project Overview

This project analyzes Amazon sales data using SQL and Power BI to identify sales trends, product performance, category performance, and brand performance.

The project demonstrates practical data analysis and business intelligence skills, including SQL data analysis and interactive Power BI dashboard development.

## Tools & Technologies

- SQL
- Power BI
- Data Analysis
- Data Visualization

## Dataset

The dataset contains Amazon sales information including:

- Order ID
- Order Date
- Customer ID
- Customer Name
- Product ID
- Product Name
- Category
- Brand
- Quantity
- Unit Price

## SQL Analysis

SQL was used to analyze the sales data and answer business questions using:

- SELECT
- WHERE
- JOIN
- GROUP BY
- HAVING
- ORDER BY
- Aggregate Functions
- CASE Statements
- Subqueries
- Window Functions

## Key Analysis

The analysis focused on:

- Total sales
- Total orders
- Total quantity sold
- Average order value
- Sales by category
- Sales by brand
- Top 10 products by sales
- Monthly sales trends
- Quantity sold by category
